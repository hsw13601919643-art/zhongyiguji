# 部署文档

> 对应验收项：M05-01 至 M05-07；交付物清单第 6 项
> 版本：V1.0（一期纯前端版）＋ 二期服务器部署规划

## 1. 一期：纯前端版

### 1.1 运行环境

| 项目 | 要求 |
|---|---|
| 电脑 | Windows 10 及以上 / macOS 12 及以上；Chrome、Edge、360 极速模式（Chrome 内核）最新版 |
| 手机 | iOS 14 及以上、Android 9 及以上；微信内置浏览器、Safari、Chrome |
| 服务器（可选） | 任意静态网页服务器（Nginx、IIS、Apache、对象存储静态网站） |

### 1.2 三种使用方式

**方式一：直接打开（演示、需求确认）**
1. 下载或复制整个项目文件夹（保持目录结构不变）。
2. 双击根目录 `index.html`，用 Chrome 或 Edge 打开。
3. 数据保存在当前浏览器中；换电脑或换浏览器后为示例数据。

> 注意：本地文件方式下，手机无法通过二维码访问，推广请采用方式二或方式三。

**方式二：局域网/内网服务器（推荐用于试运行）**
1. 将项目文件夹上传到服务器，例如 `/usr/share/nginx/html/yaoshan/`。
2. Nginx 配置示例：
   ```nginx
   server {
     listen 80;
     server_name yaoshan.example.local;          # 改为实际域名或 IP
     root /usr/share/nginx/html/yaoshan;
     index index.html;
     charset utf-8;
     location ~* \.(md|csv)$ { charset utf-8; default_type text/plain; }
     location ~* \.(js|css|svg)$ { expires 7d; }
   }
   ```
3. 浏览器访问 `http://服务器地址/`，即可在同一网络内的电脑、手机使用。

**方式三：云服务器 / 对象存储（推荐用于推广）**
1. 申请域名并完成 ICP 备案（微信内访问需要备案域名）。
2. 将项目上传至阿里云 OSS / 腾讯云 COS 静态网站托管，或云服务器 Nginx。
3. 配置 HTTPS 证书（免费证书即可）。
4. 在“推广中心”填写正式访问地址，生成各点位二维码。

### 1.3 更新数据

| 内容 | 方法 |
|---|---|
| 药膳方 | 管理端“药膳方管理”在线编辑，或批量导入 CSV |
| 示例数据 | 修改 `m01-database/data/recipes.js` 后提高 `recipesVersion` 版本号；未被修改过的浏览器会自动更新 |
| 规则 | 管理端“推荐规则配置” |
| 科普 | 管理端“科普内容管理” |

> 一期数据保存在各自浏览器中，**多台电脑之间不会同步**。需要统一数据时，在维护电脑上导出备份，再在其他电脑上恢复；正式多人使用请采用二期。

### 1.4 备份与恢复

- 管理端 → 数据备份与恢复 → “导出全部数据”，得到 `.json` 备份文件，建议每周导出一次并妥善保存。
- 恢复：同页面选择备份文件 → 确认恢复。
- 自动快照：修改药膳方、规则、内容时自动创建，保留最近 5 份。

## 2. 二期：服务器版（规划）

### 2.1 架构

```
微信小程序 / H5 ──HTTPS──> Nginx ──> 应用服务（Python FastAPI 或 Java Spring Boot）
                                      ├── 推荐引擎（沿用一期规则与算法）
                                      ├── MySQL / PostgreSQL
                                      └── 定时备份 → 对象存储（异地）
互联网医院平台 / 长者食堂系统 / 数智化产品 ──HTTPS + API Key──> 开放接口（见《接口文档》）
```

### 2.2 服务器配置建议

| 项目 | 建议 |
|---|---|
| 云服务器 | 2 核 4 GB，系统盘 40 GB，数据盘 100 GB，带宽 5 Mbps |
| 数据库 | MySQL 8.0 / PostgreSQL 15（可用云数据库，开启自动备份） |
| 系统 | Linux（CentOS Stream / Ubuntu 22.04 LTS） |
| 证书 | HTTPS 证书 |
| 账号归属 | 服务器、域名、小程序、云数据库均以甲方名义开通 |

### 2.3 部署步骤（二期交付时细化）

1. 初始化数据库，执行建表脚本（表结构见《数据库设计说明书》第 6 节）。
2. 将一期导出的 CSV / 备份 JSON 导入数据库。
3. 部署应用服务，配置数据库连接、API Key、日志目录。
4. 配置 Nginx 反向代理与 HTTPS。
5. 前端改为调用服务器接口（替换 `assets/js/db.js` 与 `m05-deploy/api.js` 的实现）。
6. 微信小程序：以甲方主体注册，配置服务器域名白名单，提交审核发布。
7. 运行覆盖测试（`m04-engine/index.html`）与性能测试，确认响应时间 < 3 秒。
8. 配置每日自动备份与监控告警。

### 2.4 试运行（1—3 个月）

- 记录运行日志、故障与处理情况（验收项 M05-07）。
- 每周检查备份是否成功，每月做一次恢复演练。
