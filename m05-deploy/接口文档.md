# 接口文档（预留接口）

> 对应验收项：M05-04；方案 4.3“预留与医院互联网医院平台、社区长者食堂系统、中医数智化产品的数据接口”
> 一期：`m05-deploy/api.js` 在浏览器内模拟，可在 `m05-deploy/index.html` → “接口演示”中调用；二期：以下地址以 HTTPS 正式提供。

## 1. 通用约定

| 项目 | 约定 |
|---|---|
| 地址 | `https://{正式域名}/api/v1/...` |
| 格式 | 请求、返回均为 JSON，UTF-8 |
| 鉴权 | 请求头 `X-Api-Key: {分配给对接方的密钥}`；密钥由甲方管理员发放，可随时停用 |
| 限流 | 每个密钥每分钟 600 次（可调整） |
| 时间 | 日期格式 `YYYY-MM-DD` |

**统一返回结构**

```json
{ "code": 0, "message": "ok", "data": { }, "requestId": "REQ...", "elapsedMs": 1.2 }
```

| code | 含义 |
|---|---|
| 0 | 成功 |
| 40001—40006 | 参数错误（体质、脏腑、节气、日期、问卷答案不合法或不完整） |
| 40100 | 未提供或无效的 API Key |
| 40400 | 资源不存在或未发布 |
| 50000 | 服务器内部错误 |

**取值范围**：体质为九种体质标准名（如“气虚质”）；脏腑为 肝/心/脾/肺/肾；节气为二十四节气标准名；年龄段为 儿童/青少年/青年/中年/老年；地域为 江南/华北/西北/东北/岭南/西南/其他。

## 2. 接口清单

| # | 方法 | 地址 | 名称 | 主要对接方 |
|---|---|---|---|---|
| 1 | POST | `/api/v1/recommend` | 三餐推荐 | 互联网医院平台、数智化产品 |
| 2 | POST | `/api/v1/recommend/seasonal` | 四季方案 | 互联网医院平台、数智化产品 |
| 3 | POST | `/api/v1/canteen/menu` | 长者食堂每日菜单 | 社区长者食堂系统 |
| 4 | GET | `/api/v1/recipes` | 药膳方检索 | 全部 |
| 5 | GET | `/api/v1/recipes/{id}` | 药膳方详情 | 全部 |
| 6 | POST | `/api/v1/constitution/evaluate` | 体质判定 | 数智化产品（自有问卷） |
| 7 | GET | `/api/v1/solar-term` | 当前节气 | 全部 |
| 8 | GET | `/api/v1/yaoshi` | 药食同源目录 | 全部 |

## 3. 接口说明

### 3.1 三餐推荐 `POST /api/v1/recommend`

请求（各项均可省略；`term` 省略时为当天节气）：

```json
{ "constitution": "气虚质", "term": "立冬", "organ": "脾", "age": "老年", "region": "江南" }
```

返回 `data`：

```json
{
  "term": "立冬", "season": "冬",
  "meals": {
    "breakfast": { "pick": { "id": "YS0028", "name": "枣姜汤", "efficacy": "健脾和胃，温中进食", "category": "茶饮", "reasons": ["体质：气虚质", "调补脾", "冬季"] }, "alternatives": [ … ] },
    "lunch":     { "pick": { … }, "alternatives": [ … ] },
    "dinner":    { "pick": { … }, "alternatives": [ … ] }
  },
  "appliedRules": ["R03", "R10", "R23", "R30"],
  "filtered": 2
}
```

### 3.2 四季方案 `POST /api/v1/recommend/seasonal`

请求同 3.1（不含 `term`）。返回 `data` 为 `{ "春": {同3.1}, "夏": {…}, "秋": {…}, "冬": {…} }`，分别以春分、夏至、秋分、冬至为代表节气。

### 3.3 长者食堂每日菜单 `POST /api/v1/canteen/menu`

供长者食堂系统每天拉取菜单，按就餐老人主要体质分别给出三餐建议。

```json
{ "date": "2026-11-11", "region": "江南", "age": "老年", "constitutions": ["平和质", "气虚质", "阳虚质"] }
```

返回 `data`：`{ "date", "term", "tip"（节气养生提示）, "menus": [ { "constitution": "平和质", "plan": {同3.1} }, … ] }`

### 3.4 药膳方检索 `GET /api/v1/recipes`

参数：`keyword`、`constitution`、`organ`、`season`、`page`（默认 1）、`size`（默认 20，最大 100）。仅返回已发布方剂。
返回 `data`：`{ "total", "page", "size", "items": [药膳方] }`

药膳方对象：`id, name, alias, source, original, composition[{name, amount, type}], efficacy, indication, ages, constitutions, organs, seasons, terms, meals, category, nature, yaoshi{compliant, note}, method, cautions, sample`

### 3.5 药膳方详情 `GET /api/v1/recipes/{id}`

返回单个药膳方对象；未发布或不存在返回 `40400`。

### 3.6 体质判定 `POST /api/v1/constitution/evaluate`

对接方使用本系统问卷（题号 q1—q60，题目见 `m02-user/constitution-data.js`）时，提交答案获取判定结果。

```json
{ "answers": { "q1": 3, "q2": 1, "…": 5 } }
```

返回 `data`：`{ "primary": "气虚质", "secondary": [], "scores": { "平和质": 50, … }, "judge": { "平和质": "否", … } }`

### 3.7 当前节气 `GET /api/v1/solar-term?date=2026-11-11`

返回 `data`：`{ "date", "term": "立冬", "season": "冬", "tip", "next": { "term": "小雪", "date": "2026-11-22", "days": 11 } }`

### 3.8 药食同源目录 `GET /api/v1/yaoshi?keyword=枣`

返回 `data`：`[ { "no", "name", "aliases", "batch", "note" } ]`

## 4. 对接流程

1. 对接方提交申请（单位、用途、调用量、联系人）。
2. 甲方管理员发放 API Key（测试环境、正式环境各一个）。
3. 对接方在测试环境联调，双方确认结果。
4. 正式上线；甲方可在管理端查看各密钥的调用量（二期）。

## 5. 安全要求

- 全部接口仅支持 HTTPS；API Key 不得写入前端页面或小程序代码，须由对接方服务器调用。
- 接口不返回、不接收任何患者身份信息。
- 调用记录写入日志，保存不少于 6 个月。
