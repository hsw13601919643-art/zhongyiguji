# 操作手册

> 经典药膳方数据库及“三餐四季”推荐系统 V1.0（纯前端版）
> 对应交付物清单第 7 项《操作手册》；验收项 M07-05

## 第一部分　用户端（市民、长者使用）

### 1. 打开系统
- **手机**：微信扫描推广海报上的二维码；或在浏览器中打开系统网址。
- **电脑**：打开系统首页，点击“用户端”。
- **触摸屏**：在社区、长者食堂的触摸屏上直接点选。

首次打开会弹出“使用前请阅读”，点击“同意并继续”后，测评结果和收藏会保存在您的手机上；点击“暂不同意”仍可浏览，但不会保存。

### 2. 体质测评
1. 首页点击“体质测评”或“开始测评”。
2. 选择性别、年龄段、所在地域，点击“开始测评”。
3. 共 60 题，按近一年的感觉选择“没有 / 很少 / 有时 / 经常 / 总是”，选择后自动进入下一题；可点“上一题”修改，可点“稍后再答”中途退出（进度会保留）。
4. 答完点击“查看结果”，显示主要体质、兼有倾向、各体质得分和饮食调养建议。
5. 点击“保存并查看推荐药膳”。

已知道自己体质的，可在测评页下方“直接选择”。

### 3. 查看三餐推荐
1. 底部点击“推荐”。
2. 页面上方可调整：体质、节气（默认当天）、调理脏腑（肝心脾肺肾）、年龄段、地域。
3. 下方显示早餐、午餐、晚餐各一道药膳，包括方名、功效、组成（绿色为药食同源药材）、制作方法与注意事项；“匹配”标签说明推荐理由。
4. 不喜欢可点“换一个”。
5. 点“四季方案”查看春夏秋冬四套方案。

### 4. 药膳详情
点击方名进入详情，可查看古籍出处与原文、组成、功效、适宜人群、制作方法、注意事项、现代研究。

### 5. 收藏与分享
- 点击“☆ 收藏”收藏单个药膳，点击“收藏方案”收藏整套三餐方案；在底部“收藏”中查看。
- 点击“分享”：手机浏览器会调出系统分享；微信中请点右上角“···”发送给朋友；也可复制链接或扫码。

### 6. 清除数据
“收藏”页底部点击“清除本机数据”，或在《隐私政策》页点击“撤回同意并清除本机数据”。

## 第二部分　管理端（工作人员使用）

### 1. 登录与角色

| 角色 | 主要工作 |
|---|---|
| 系统管理员 | 全部功能：发布/下架、删除、规则配置、日志、备份 |
| 数据录入员 | 新增、编辑、批量导入药膳方，提交审核 |
| 审核专家 | 审核药膳方（通过/驳回），导出数据，查看统计 |
| 内容运营 | 科普内容编辑与上下架，查看用户与统计 |

系统首页 → 管理端，输入用户名和密码登录。连续输错 5 次锁定 5 分钟。（演示账号见登录页）

### 2. 药膳方录入与发布
1. **新增**：药膳方管理 → “新增药膳方”，填写方名、古籍名称、组成（每行一味：名称、标准名、用量、类型）、功效、适用体质/脏腑/季节/餐次等，保存为草稿。组成区会实时提示是否符合药食同源目录。
2. **批量导入**：点击“下载模板”，用 Excel 按模板填写后另存为 CSV（UTF-8），点击“批量导入”上传；有问题的行会列出行号和原因，修改后重新导入。导入的方剂为“待审核”。
3. **提交审核**：草稿点击“提交审核”。
4. **审核**（审核专家）：点击“审核”，查看全部字段，填写意见后“审核通过”或“驳回”（驳回须写理由）。
5. **发布**（管理员）：审核通过后点击“发布”，用户端即可看到；不再使用时点击“下架”。
6. **历史版本**：每次保存自动保留旧版本，点击“版本”可查看并恢复。
7. **导出**：点击“导出 CSV”导出当前筛选结果。

### 3. 推荐规则配置（管理员）
- 规则列表可勾选启用/停用、编辑、删除，或“恢复默认规则”。
- 编辑规则：设置触发条件（季节、节气、脏腑、体质、年龄段、地域），以及偏好（加分）和规避（扣分）的功效标签、五味、五色、四气、类别、组成，设置权重 1—30。
- 右上“规则预览”可输入条件试算。
- 修改后建议到“算法测试台”运行覆盖测试。

### 4. 用户、统计与科普
- **用户与推荐记录**：查看匿名用户的体质、年龄段分布和每次推荐记录，可导出。
- **数据统计**：查看访问量、推荐次数、热门方剂、推广来源；管理员可生成/清除演示数据。
- **科普内容管理**：新增图文或视频内容，正文段落之间空一行，“>”开头为引文；保存后点击“上架”用户端可见。

### 5. 数据安全
- **操作日志**：按时间、人员、结果查询，可导出。
- **数据备份与恢复**：建议每周“导出全部数据”保存备份文件；需要时选择备份文件恢复。

### 6. 推广
推广中心 → 填写正式网址、场景类别、点位名称 → 生成海报 → 打印张贴；点击“保存为推广点位”，部署后把状态改为“已部署”。扫码访问量会按点位统计。触摸屏终端打开“触摸屏模式”，无人操作 90 秒自动回到首页。

## 第三部分　常见问题

| 问题 | 处理 |
|---|---|
| 换了电脑，数据不见了 | 一期数据保存在各自浏览器中。在原电脑导出备份，在新电脑恢复。 |
| 手机扫码打不开 | 二维码须使用部署后的正式网址生成；本地文件方式无法扫码。 |
| 导入提示“表头不符合模板” | 请使用系统下载的模板，不要修改第一行；保存为 CSV UTF-8 格式。 |
| 某首方剂不出现在推荐中 | 检查是否“已发布”，以及组成中的药材是否都在药食同源目录内。 |
| 忘记密码 | 一期为演示账号；二期由管理员重置。 |
