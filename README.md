# 经典药膳方数据库及“三餐四季”推荐系统

> 基于“药食同源”理论中医经典古籍药膳方溯源与创新转化项目（项目编号 PDZY-2026-0315）
> 委托方：上海市第七人民医院 ｜ 当前版本：V1.0 纯前端版（用于需求确认与演示）

**在线演示**：https://hsw13601919643-art.github.io/zhongyiguji/ （GitHub Pages，启用后可访问）

## 快速开始

1. 下载或克隆整个项目文件夹（保持目录结构不变）。
2. **双击根目录 `index.html`**，用 Chrome 或 Edge 打开，即进入系统门户。
3. 门户提供四个入口：**用户端**、**管理端**、**推广终端**、**验收导航**。

管理端演示账号（点击登录页表格可自动填入）：

| 角色 | 用户名 | 密码 |
|---|---|---|
| 系统管理员 | admin | admin123 |
| 数据录入员 | editor | editor123 |
| 审核专家 | reviewer | review123 |
| 内容运营 | operator | oper123 |

> 纯前端版的数据保存在当前浏览器中；换电脑或换浏览器后会显示示例数据。需要让手机扫码访问时，请部署到服务器（见《部署文档》）。

## 待甲方确认 / 补充的事项

1. **示例数据审核**：33 首示例方的出处、原文、组成依古籍整理，适用体质、脏腑、节气等为现代解读，均须甲方文献团队与专家审核；正式数据请按录入模板整理后批量导入。
2. **药食同源目录核对**：106 种目录须与国家卫健委、市场监管总局公告原文逐一核对。
3. **体质问卷条目**：须对照《中医体质分类与判定》标准原文核对。
4. **推荐规则**：方案示例 3 条以外新增的 20 条规则须专家确认。
5. **扩展字段**：为实现三餐推荐与五行规则，药膳方增加了 6 个扩展字段（见需求变更确认单 BG-2026-002）。
6. **收录数量**：药膳方收录数量以任务书及专家论证为准。

## 维护说明

- 修改或新增任何 `.md` 文档后，在项目根目录运行 `python3 tools/build_docs.py`，文档查看器才能在双击打开时显示最新内容。
- 修改示例药膳方（`m01-database/data/recipes.js`）后，提高文件末尾的 `recipesVersion`；未在管理端修改过数据的浏览器会自动更新。
- 第三方组件：`assets/lib/qrcode.js`（qrcode-generator 1.4.4，MIT 许可证）。
