# 成果归属与保密要点

> 对应验收项：M08-02“成果归属”、M08-03“保密义务”；依据方案第八章
> 用途：供甲方起草或审核委托合同时参考，最终以法律顾问审定的合同文本为准。

## 1. 知识产权归属（方案八.1）

建议合同写明：

1. 本项目产生的数据库、推荐系统软件（含源代码、文档、数据、界面设计）的著作权及其他知识产权**归甲方上海市第七人民医院所有**。
2. 乙方协助甲方申请软件著作权，甲方为权利人；申请所需材料由乙方按甲方要求提供。
3. 乙方不得擅自使用、复制、转让、许可他人使用本项目成果，也不得将其用于其他项目或产品。
4. 乙方在项目中使用的第三方开源组件，须列明名称、版本和许可证，并保证不侵犯第三方权利（本项目一期仅使用 qrcode-generator，MIT 许可证）。

## 2. 成果移交清单（验收时核对）

| # | 内容 | 形式 | 核对 |
|---|---|---|---|
| 1 | 全部源代码（含历史版本记录） | 代码仓库或光盘 | ☐ |
| 2 | 结构化数据库（全部药膳方、目录、规则、内容） | CSV / JSON 备份 / 数据库导出 | ☐ |
| 3 | 全部交付文档（见交付物清单） | 电子版 + 纸质版 | ☐ |
| 4 | 服务器、域名、小程序、云数据库等账号（二期） | 账号及权限移交单 | ☐ |
| 5 | 第三方组件清单及许可证 | 文档 | ☐ |
| 6 | 乙方留存数据的删除承诺 | 书面承诺 | ☐ |

## 3. 保密（方案八.2）

| 项目 | 建议条款 |
|---|---|
| 保密内容 | 甲方提供的古籍文献整理成果、药膳方数据、专家意见、业务信息、未公开的项目资料 |
| 保密期限 | 自合同签订之日起至项目结束后 **5 年** |
| 义务 | 不向第三方泄露；仅限项目组成员知悉且须签署保密承诺；项目结束后归还或销毁 |
| 例外 | 已公开信息；依法须披露的信息（须事先通知甲方） |
| 违约责任 | 按合同约定承担赔偿责任 |

## 4. 数据安全（方案八.3）

- 遵守《数据安全法》《个人信息保护法》，系统不得存储患者个人信息。
- 系统须具备权限管理、操作日志、数据备份功能（见 M06《安全说明》）。
- 乙方人员不得在个人设备上留存项目数据；测试数据使用示例数据。
