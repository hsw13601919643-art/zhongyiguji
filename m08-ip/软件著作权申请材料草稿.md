## 2. 软件说明（申请表“软件功能和技术特点”）

**开发的硬件环境**：普通 PC（CPU 2 核以上，内存 8 GB）。
**运行的硬件环境**：电脑、手机、触摸屏终端；服务器（二期）2 核 4 GB 以上。
**开发该软件的操作系统**：Windows / macOS / Linux。
**软件开发环境/开发工具**：Visual Studio Code、Chrome 开发者工具。
**该软件的运行平台/操作系统**：Windows、macOS、Android、iOS（浏览器及微信内置浏览器）。
**软件运行支撑环境/支持软件**：现代浏览器（Chrome、Edge、Safari、微信内置浏览器）。
**编程语言**：HTML、CSS、JavaScript（二期增加 Python 或 Java）。
**源程序量**：约（待统计，提交前以最终版本统计行数）行。

**开发目的**：整理中医经典古籍药膳方，建立结构化数据库，基于中医体质学说、脏腑学说、五行学说及“三应”原则，为社区居民、长者等提供个性化“三餐四季”药膳推荐与科普。

**面向领域/行业**：医疗卫生、中医药健康服务。

**软件的主要功能**（不超过 1300 字，提交前精简）：
1. 经典药膳方数据库：收录古籍药膳方，包含方名、出处、组成、功效、适用年龄、适用体质、调补脏腑、适用节气、药食同源应用、制作方法、注意事项、现代研究、数据来源等字段；内置 106 种药食同源目录并自动核验；支持批量导入、在线编辑、版本管理、专家审核与发布。
2. 中医体质辨识：采用标准问卷自动计分，判定九种体质及兼夹体质。
3. 三餐四季推荐：依据体质、节气（自动识别当前节气）、脏腑、年龄、地域，通过“规则引擎＋标签匹配”生成早、中、晚三餐及四季药膳方案，并说明推荐理由；自动过滤非药食同源药材。
4. 管理功能：推荐规则配置、用户体质统计、推荐记录、访问与热门方剂统计、科普内容管理。
5. 数据安全：角色权限、操作日志、数据备份与恢复、知情同意与个人信息保护。
6. 推广应用：场景二维码与海报生成、按点位统计、触摸屏终端模式、对外数据接口。

**软件的技术特点**：
1. 分层打分的规则引擎：体质、脏腑、时令、年龄、五行色味分层计分，保证“辨体施膳”优先且结果可解释；
2. 二十四节气自动计算与“应时、应地、应体”规则体系；
3. 药食同源目录自动合规核验；
4. 跨终端自适应（电脑、手机、微信、触摸屏），可脱离服务器运行。
