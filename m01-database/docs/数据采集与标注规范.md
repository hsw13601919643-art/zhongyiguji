# 药膳方数据采集与标注规范

> 项目编号：PDZY-2026-0315 ｜ 版本：V1.0 ｜ 对应验收项：M01-01、M01-03、M01-04、M01-11、M01-12，交付物清单第 2 项
> 状态：初稿，待甲方文献团队与专家确认

## 1. 分工

| 环节 | 负责方 | 产出 |
|---|---|---|
| 确定纳入书目 | 甲方组织专家论证会 | 纳入书目清单 |
| 古籍查阅与初步整理 | 甲方文献团队 | 按模板整理的药膳方表格 |
| 数字化处理、清洗、标准化标注 | 乙方 | 校验通过的结构化数据 |

## 2. 采集范围

1. **古籍**：以《黄帝内经》《金匮要略》《饮膳正要》《千金方·食治门》《养老奉亲书》《本草纲目》等为主，以专家论证会确定的书目为准。
2. **现代规范**：国家卫健委 2024 年 8 月《药食同源目录》（106 种）、《药膳制作通用规范》。
3. **现代研究**：中国知网等数据库中的方剂演变、药膳现代研究论文。

## 3. 采集流程

1. 下载录入模板 `m01-database/template/recipe-import-template.csv`，用 Excel 打开，删除示例行。
2. 每首方剂一行，按第 4 节填写。
3. 在管理端“药膳方管理 → 批量导入”上传；系统逐行校验，错误行显示行号与原因，修改后重新导入。
4. 导入成功的方剂为“待审核”状态，由审核专家逐条审核。
5. 审核通过后由管理员发布，用户端即可检索、推荐。

## 4. 标注规则

### 4.1 方名与出处
- 方名照录古籍；同方异名填入“别名”。
- 古籍名称不加书名号；卷次篇目写作“卷二·食疗诸病”；原文摘录照录，不改字，异体字按通行规范字录入并在备注说明。
- “数据来源”写明所据版本（出版社、年份）及页码，电子资源附链接。

### 4.2 组成
- 格式：`名称:用量:类型`，多项以“；”分隔。
- 类型：药（药材）/ 食（普通食材）/ 调料。判断标准：在《中国药典》或药食同源目录中作为药材使用的记为“药”。
- 名称与目录名称不一致时写标准名：`生地黄汁=地黄:一升:药`、`陈皮=橘皮:二钱:药`。
- 用量照录古籍原文；现代参考用量写入“制作方法”，并注明“参考”。古今剂量换算由专家确定。

### 4.3 体质、脏腑、节气（现代解读，须专家确认）
- 适用体质：只选“宜”的体质，依据功效、四气与主治判断；不确定时留空，由专家补充。
- 调补脏腑：选主要作用脏腑，最多 3 个；相关病症写入“主治病症”。
- 适用季节：按四气与功效判断（如温补类宜冬、清热祛湿类宜夏）；四季皆宜则全选；如古籍明确时令，可填写具体节气。

### 4.4 扩展字段
- 适用餐次：粥类一般为早、晚；汤羹菜肴为午、晚；茶饮按功效确定。安神类宜晚，温中散寒类宜早。
- 四气五味、五色：依据主要组成的性味与成品颜色标注。
- 功效标签：从字典 `tags` 中选取 2—5 个，与“功效”描述一致。

### 4.5 注意事项与现代研究
- 注意事项须写明禁忌证、慎用人群（孕妇、婴幼儿、过敏体质、慢病患者等）及与药物的配伍禁忌。
- 现代研究每条记录题录信息（题名、作者、刊名、年份、链接），并撰写 100 字以内摘要；无可靠文献时留空，不得臆造。

## 5. 质量控制

| 检查项 | 方法 | 要求（建议，待双方确认） |
|---|---|---|
| 字段完整 | 系统校验 + 抽检 | 必填字段无缺漏 |
| 取值规范 | 系统校验 | 体质、脏腑、节气等无非标准值 |
| 无重复 | 按方名 + 出处查重 | 同出处同名方仅一条 |
| 内容准确 | 专家抽检 | 抽检不少于 10% 且不少于 20 首，准确率 ≥ 95% |
| 药食同源合规 | 系统自动核验 | 含目录外药材的方剂只作文献记录，不进入推荐 |

## 6. 审核要点（专家）

1. 出处、原文与所据版本一致；
2. 组成、用量照录无误，标准名对应正确；
3. 适用体质、脏腑、季节标注合理；
4. 制作方法安全可行，注意事项完整；
5. 驳回时须填写理由，录入人修改后重新提交。
